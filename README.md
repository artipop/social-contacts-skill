# Контакты из соцсетей — скилл для ИИ-агентов

Сборщики контактов из Telegram, Instagram и VK для десктопных ИИ-агентов (Claude Code, Codex, Cursor): участники открытых Telegram-каналов и групп, поиск людей среди подписчиков Instagram-профиля и подписчиков VK-сообщества. Telegram и Instagram читаются из обычного Chrome пользователя, в котором он уже вошёл в аккаунты; VK работает через API с токеном пользователя. Собранные данные остаются на машине пользователя. Go-модуль `github.com/artipop/social-contacts-skill`; CLI и скилл появятся позже.
